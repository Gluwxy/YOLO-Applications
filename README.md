# YOLO-Applications 👁️🤖

Welcome to **YOLO-Applications**, a repository dedicated to practical, real-world computer vision solutions. This collection explores advanced object detection, semantic segmentation, and video processing workflows utilizing state-of-the-art deep learning models.

The projects housed here span various domains—from urban infrastructure analysis to environmental and agricultural monitoring—focusing on robust, optimized, and deployment-ready architectures.

## 🧰 Tech Stack & Tools

Across the different applications in this repository, you will find implementations utilizing:
* **Deep Learning Models:** Ultralytics YOLOv8, YOLO26, DeepLabV3+
* **Inference Optimization:** SAHI (Sliced Aided Hyper Inference), Edge AI quantization (ONNX, INT8)
* **Computer Vision:** OpenCV (Homography, ORB Feature Matching, Video I/O)
* **Spatial & Geometric Analysis:** Shapely, NumPy
* **Pipelines & Tracking:** Roboflow, custom tracking algorithms
